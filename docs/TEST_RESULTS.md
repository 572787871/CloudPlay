## 实际遇到并修复的问题

- Docker tmpfs 的 YAML 逗号解析、非 root 健康脚本权限、nginx 上游证书链验证深度，均已在实际部署后修复验证。
- Aria2 缺失 Secret 返回 HTTP 400 + JSON error，验收检查两层错误。
- Caddy 2.11.9 当时 registry 返回 manifest unknown，使用真实可拉取的 2.11.8，没有虚构镜像。
- SwiftUI 后续 Torrent 导航闭包参数写法导致编译失败，改为明确参数后通过。
- Intel Runner 测试准备耗时较长，显式启动最新已安装模拟器并临时签名测试 App，最终完整通过；另外完成 ARM Runner 验证。被取消的旧运行没有被计为通过。
- CocoaPods 上游许可证文本含换页符，造成生成 XML 非法；构建时仅将分页符规范为换行，保留全部版权/许可文字，并用 plutil 和打包脚本校验。
